# Simulacro · Cuestionario Final — Data Science Programming

Simulacro interactivo del cuestionario final del módulo de Data Science Programming
(Especialización en Ciencia de Datos, Universidad Santo Tomás — Tunja).

50 preguntas autocalificables (opción múltiple, selección múltiple y verdadero/falso),
varias con gráficas, tablas de DataFrame y fragmentos de código. Material de práctica,
no evaluado.

Sitio estático de un solo archivo (`index.html`), sin dependencias ni recursos externos.

## Uso local
Abre `index.html` en cualquier navegador.

## Despliegue
Desplegado en Vercel como sitio estático desde la raíz del repositorio.
